## 3. 必读约束

### 3.1 反直觉点

1. **`phone` min(11)**：修改时 phone 少于 11 位 → 400（schema 校验）。
2. **`name` min(2)**：修改时 name 少于 2 字 → 400。
3. **`email` 允许空串**：`z.literal('')` 联合（可清空邮箱）。
4. **权限 403 用 interviewer**：`candidate:update` 矩阵里 interviewer 无权限（与 create 不同——create 是 hr 不允许？不，create 需要 `candidate:create`，interviewer 无）。
5. **404 场景**：不存在的候选人 id（cuid 格式）→ service 校验候选人不存在 → 404。

### 3.2 不需要 mock

本 e2e 是真接口测试（不 mock）。
